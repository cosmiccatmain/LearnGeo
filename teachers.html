How a class runs

Four things you do once, then it is just marking.

A class in LearnGeo is a name, a short code and a list of assignments. All three live in your browser, and codes are how they travel to your students and back again.

01

Name your class

It gets a short code of its own, like 8RLJQU. Write it on the board. That code is what tells a student's app which class they belong to.

02

Write the assignments

Pick the countries one at a time or drop in a whole continent, then choose the mode, the length, the question types and whether it is timed.

03

Share one join code

The join code carries the class and every assignment in it. Paste it into your class chat once. Add work later and you just send the new code.

04

Collect the results

Students send a short result code back. Paste up to twenty at a time, or type a score straight into the gradebook if someone worked on paper.

What you can set

Exactly the countries you covered, under the conditions you want.

An assignment is a list of places plus a set of rules. Nothing in it is fixed to a syllabus, so a revision list of eleven awkward capitals is as valid as a whole continent.

  • A named list of countriesType them in one at a time, or add a whole region with one button.
  • Exam conditionsHold every result back until they submit, and put the section on a clock.
  • Typed answersTurn off multiple choice so they have to spell it themselves.
  • Any of the four modesA scored practice test, open practice, flashcards, or the class map quiz where they click the country and write its name and capital.

What the class screen gives you

  • Twenty results in one pasteStudents send a short code each. Paste the lot in together and they sort themselves onto the right names.
  • A score you can type inAnyone who worked on paper or lost their code still gets a row.
  • What the class keeps missingThe analytics tab ranks the countries the whole class gets wrong, so you know what to reteach.
  • A CSV when you need oneExport the gradebook and put it wherever your school keeps marks.
Privacy

No accounts, and nothing leaves the room.

Students never give an email address or a password, because there is nothing to sign into. Your class, your assignments and every score you collect are stored in your own browser and are never uploaded anywhere.

That cuts both ways, and it is worth knowing before you start a term on it: the class lives on the machine you built it on. Clearing your browser storage clears the gradebook with it, so export the CSV at the end of a unit if the marks need to outlive the browser.
