### 2. The admin keypad does not fail closed

A hardcoded four-digit code is live at `assets/js/admin.js:18` and is checked
before Supabase is ever consulted (`if (typed === CODE) return pass();`). It is
present on main and on all six `claude/*` branches. `AdminPin.verify()` returns
`Promise.resolve(false)` — not `null` — when `Cloud.sb` is missing, so the caller's
`if (!asking) return fail()` never fires; offline the keypad still opens on the
built-in code. Only one commit has ever touched `assets/js/admin-pin.js`.

So nothing in this repository matches the fail-closed state the briefing
describes, and main deploys to www.learngeo.app. The blast radius is limited —
the panel edits this browser's own save, and the file says as much — but the
hazard note is inverted: there is no removal to protect, there is a shipped code
to decide about. Owen's or aj's call.

### 3. epic-mccarthy breaks more than the teacher dashboard

`public.announcements` is confirmed absent from the live database (tables are
`profiles`, `classes`, `class_members`, `assignments`, `results`, `arcade_scores`,
`admin_pins`).

The new reads are not isolated to the Stream tab. In `assets/js/cloud.js` on that
branch, `from('announcements').select(...)` sits inside the same `Promise.all` as
the assignments, results and members reads — in the teacher's class sync, and
again in the **student's** assignment refresh. `check()` throws on `res.error`.
A missing table therefore throws in both chains: teachers lose class sync and
students stop receiving assignments.

Gate unchanged, reason stronger: `supabase/deployed/0001_announcements.sql` must
be applied by Owen or aj before or with that code.


## Combining keller and carson, when someone is asked to

Both fixed the same two bugs. Neither is a superset of the other overall.

- **`quiz.js` `generate()` — take Keller.** Identical shape to Carson's plus
  `if (!wanted.length) wanted = pool({ scope: config.scope });`. Without it an
  empty request yields `n = 0`: a quiz with no questions.
- **`quiz.js` `score()` — Keller only.** Carson does not touch it. Keller replaces
  the flat `-1` for unseen countries with `-1 + Math.random() * 0.9`, so a new
  learner's first deck stops being the same run down Africa.

  bug. Keller sorts into two buckets (any prefix, then any substring); Carson
  ranks four ways, so a name prefix beats a capital prefix. Strictly finer.

  answers cost (`pay(false, ...)` twice, with a `quiet` flag so the wrong sound
  plays once); Keller adds `score-hero--center` to the class-quiz report. Separate
  hunks.
